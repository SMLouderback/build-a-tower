# Audio attribution

Procedural **filtered-noise room-tone beds** and short mechanical one-shots for Build-A-Tower
(generated by `Tools/generate_ambient_wavs.py`). These replace the earlier pitched-sine
placeholders. Prefer swapping in curated CC0 field recordings when available; update this
file when assets change.

## Regenerating

```bash
python Tools/generate_ambient_wavs.py
```

Then re-enter Play Mode so `TowerAudio` reloads clips.
